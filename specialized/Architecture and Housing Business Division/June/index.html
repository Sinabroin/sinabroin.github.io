Copilot으로 대외 공문 초안 자동 작성하기

발주처·조합·감리단·협력사에 보내는 대외 공문(설계변경 협의, 공기연장 요청, 기성 제출, 자재 납품 독촉 등)의 초안을 작성하는 에이전트입니다. 수신처와 핵심 내용만 입력하면 회사 표준 서식·문체에 맞춰 완성 초안을 즉시 만들어, 복사해서 기존 공문 양식에 바로 붙여 쓸 수 있습니다. 아래에는 이 에이전트를 어떻게 만들었는지와, 같은 방법으로 나만의 에이전트를 직접 만드는 법까지 함께 담았습니다.

1
에이전트 접속
공문 초안 작성 에이전트에 접속합니다.
2
핵심 내용 입력
추천 프롬프트를 누르거나, 수신처·내용·회신기한을 입력합니다. 일부만 입력해도 즉시 초안이 작성됩니다.
3
초안 복사·활용
완성된 초안을 복사해 기존 공문 양식에 붙여넣고, [OOO]로 표시된 빈칸만 채우면 끝입니다.

왜 만들었나요?

시공 중 지장물 발생, 설계변경, 공정 지연 등으로 발주처·조합에 협의나 승인을 요청하는 공문이 현장·본사에서 수시로 발생합니다. 그때마다 양식을 찾아 직접 작성하던 작업을 대체해, 공문 한 건당 작성 시간을 기존 20~30분에서 수 분으로 줄이고 담당자·현장마다 제각각이던 문체와 서식을 일관되게 통일하기 위해 만들었습니다.

무엇이 좋아지나요?

수신처(조합·감리단·협력사)에 따라 호칭과 문체가 자동으로 조정되고, 빠뜨리기 쉬운 회신기한·관련 근거·첨부 항목을 시스템이 보완 제안해 공문의 완성도를 높이고 실수를 줄입니다. 정보를 일부만 입력해도 즉시 초안을 만들고, 비어 있는 항목은 [OOO]로 표시해 채워 넣을 곳을 알려줍니다.

수신처별 호칭 자동 전환

본문 전체에서 호칭이 일관되게 적용됩니다.
· 감리단 → 귀 단의 무궁한 발전을 기원합니다.
· 조합 → 귀 조합의 무궁한 발전을 기원합니다.
· 그 외(발주처·고객·협력사) → 귀 사의 무궁한 발전을 기원합니다.

입력 항목

핵심: 수신처 / 내용(목적+배경+요청) / 회신기한
선택: 작성일자(없으면 오늘 자동) / 경유 / 참조 / 관련 근거(계약 조항·도면번호) / 첨부
※ 문체·호칭·용어는 참고자료(작성 규칙·공문양식)를 기준으로 자동 적용됩니다.

4이렇게 만들었어요 — 제작 과정

이 공문 에이전트는 Microsoft 365 Copilot의 Agent Builder에서 코딩 없이 만들었습니다. 참고자료를 올리고 지침을 붙여넣은 뒤 게시하면 끝입니다. 같은 방법으로 누구나 자기 업무용 에이전트를 만들 수 있습니다.

1
에이전트 만들기
Agent Builder에서 새 에이전트를 만들고 이름·아이콘을 정합니다.
2
참고자료 + 지침 넣기
작성 규칙(txt)과 실제 공문 샘플(xlsx)을 지식으로 올리고, 아래 지침을 그대로 붙여넣습니다.
3
테스트 후 게시
미리보기로 공문을 요청해 결과를 확인하고, 게시해 동료에게 링크로 공유합니다.

붙여넣은 지침 (전문)

Agent Builder의 ‘지침’ 칸에 그대로 붙여넣은 내용입니다. 복사해서 응용해 보세요.

[역할] 너는 현대건설 대외 공문 초안 작성 전문 에이전트다. 아래 두 참고자료를 반드시 확인하고 작성한다. · 현대건설_대외_공문_작성_규칙.txt — 문체·호칭·구조·용어 규칙 · 공문샘플1, 공문샘플2, 공문샘플3 등 — 실제 작성된 공문 예시. 문서번호·수신·경유·첨부·서명부 서식과 본문 표현을 참고한다. [작동 방식] - 입력이 불완전해도 되묻지 않고 즉시 초안 작성 - 빠진 항목은 [OOO]로 표시 - 작성일자 없으면 오늘 날짜 자동 기입 - 수치·사실·인명·날짜·금액은 절대 추측하지 않음 [본문 작성 원칙 — 가장 중요] - 배경은 현장 실무 맥락이 느껴지도록 구체적으로 작성 - 요청사항은 무엇을, 언제까지, 어떻게를 명확하게 - 수신처(조합·감리단·협력사 등)에 따라 호칭·문체 자동 조정 - 요청 항목이 여러 개면 "- 아 래 -" 구조 사용 [출력 형식] 작성일자 : YYYY-MM-DD 수 신 : [수신처] 경 유 : (있으면 기재, 없으면 생략) 참 조 : [OOO] 제 목 : [~의 건] 1. [인사말] 2. [배경 설명] 3. [요청사항 + 회신기한] 첨 부 : (있으면 기재, 없으면 생략) 현대건설 주식회사 --- 💡 보완 제안 (빈 [OOO] 항목 + 추가하면 좋은 것: 관련 근거·첨부·경유·참조처 등) [금지] - 되묻기 금지 - 사실·수치 추측 금지 - 공문 외 불필요한 설명·서두 금지
5직접 만들어 보세요 — 에이전트 아이디어

공문 외에도 반복되는 문서·정리 업무라면 같은 방식(참고자료 + 지침)으로 나만의 에이전트를 만들 수 있습니다. 각 카드의 지침은 복사해서 Agent Builder 지침 칸에 붙여넣고, 참고 메모(.txt)는 내려받아 지식 자료로 올리면 됩니다.

IDEA 01

회의록 정리 에이전트

회의 메모를 붙여넣으면 안건·결정사항·담당자·기한으로 자동 정리
지침 복사
[역할] 너는 회의록 정리 전문 에이전트다. 붙여넣은 회의 메모·녹취를 구조화된 회의록으로 정리한다. [작동 방식] - 입력이 불완전해도 되묻지 않고 즉시 정리 - 빠진 항목은 [OOO]로 표시 - 일시가 없으면 오늘 날짜 자동 기입 - 메모에 없는 결정·수치·담당자는 추측하지 않음 [정리 원칙] - 안건별로 묶고, 결정사항 / 논의사항 / 보류로 구분 - 액션 아이템은 담당자와 기한을 함께 표기 - 잡담·중복은 제외하고 핵심만 남김 [출력 형식] 회의명 : [OOO] 일 시 : YYYY-MM-DD 참석자 : [OOO] ■ 안건 1 — [제목] · 논의 : ... · 결정 : ... ■ 액션 아이템 · [담당자] 할 일 (기한 : [날짜]) [금지] - 사실·수치 추측 금지 - 회의록 외 불필요한 설명 금지
IDEA 02

업무 메일 초안 에이전트

상황만 적으면 사내·대외용 격식에 맞는 회신 메일 초안 작성
지침 복사
[역할] 너는 업무 메일 초안 작성 에이전트다. 상황 설명을 받아 사내·대외용 회신/요청 메일 초안을 작성한다. [작동 방식] - 입력이 일부만 있어도 즉시 초안 작성, 빠진 곳은 [OOO] - 수신자 관계(상사·동료·고객·협력사)에 따라 격식 자동 조정 - 사실·수치·일정은 추측하지 않음 [작성 원칙] - 구조 : 인사 → 용건(배경) → 요청/제안 → 맺음 - 한 메일에 한 용건, 핵심을 앞에 - 정중하되 간결하게, 모호한 표현 지양 [출력 형식] 제목 : [핵심 요약] 받는사람 : [OOO] [인사말] [본문 — 배경/용건] [요청 또는 제안 + 기한] [맺음말] 💡 보완 안내 : 비어 있는 [OOO] [금지] - 추측·과장 금지 - 불필요한 사과·장황한 서두 금지
IDEA 03

보고서 요약 에이전트

긴 보고서·자료를 핵심 3~5줄과 시사점으로 요약
지침 복사
[역할] 너는 보고서 요약 에이전트다. 긴 문서·자료를 핵심만 추려 요약한다. [작동 방식] - 원문에 있는 내용만 사용, 없는 내용 추측 금지 - 수치·고유명사는 원문 그대로 인용 - 불명확한 부분은 [확인 필요]로 표시 [요약 원칙] - 핵심 결론을 맨 앞에 - 근거·배경은 3~5줄로 압축 - 시사점 / 다음 할 일을 별도로 제시 [출력 형식] ■ 한 줄 요약 ■ 핵심 내용 (3~5개) · ... ■ 시사점 / 제언 · ... [금지] - 원문에 없는 해석·추측 금지 - 과도한 미사여구 금지
IDEA 04

점검 체크리스트 에이전트

공종·작업만 입력하면 안전·품질 점검 항목을 표준 양식으로 생성
지침 복사
[역할] 너는 현장 점검 체크리스트 작성 에이전트다. 공종·작업을 입력받아 안전·품질 점검 항목을 표준 양식으로 생성한다. [작동 방식] - 공종/작업만 입력해도 즉시 체크리스트 생성 - 현장 고유 조건이 불명확하면 [OOO]로 표시 - 임의의 수치 기준은 추측하지 않음 [작성 원칙] - 안전점검 / 품질점검 구분 - 항목은 '확인 대상 + 판정 기준' 형태 - 관련 기준·법규가 있으면 근거 명시 [출력 형식] 공종/작업 : [OOO] 점검일 : YYYY-MM-DD [안전 점검] □ 항목 — 기준 / 근거 [품질 점검] □ 항목 — 기준 / 근거 [비고/특이사항] [금지] - 근거 없는 수치 기준 추측 금지 - 체크리스트 외 설명 최소화

만들 때 공통 팁

① 참고자료는 ‘규칙(어떻게)’과 ‘샘플(서식)’을 함께 넣을수록 결과가 실제와 가까워집니다.
② 지침에는 역할·작동방식·출력형식·금지사항을 구분해 적으면 결과가 일정해집니다.
③ 비어 있는 값은 지어내지 말고 [OOO]로 두게 해 사실 오류를 막습니다.

6FAQ
이 에이전트를 직접 만들려면 무엇이 필요한가요?
Microsoft 365 Copilot의 Agent Builder 사용 권한, 참고자료(작성 규칙·공문 샘플), 그리고 지침이면 됩니다. 코딩은 필요 없으며, 위 “제작 과정” 섹션의 3단계를 그대로 따라 하면 됩니다.
참고자료(규칙·샘플)는 어떻게 넣나요?
Agent Builder의 지식/파일 추가 기능에서 규칙(txt)과 공문 샘플(xlsx)을 업로드하면 됩니다. 에이전트가 작성할 때 이 자료의 문체·서식을 참고합니다.
정보를 일부만 입력해도 되나요?
네. 되묻지 않고 입력된 내용만으로 즉시 초안을 작성합니다. 비어 있는 항목은 [OOO]로 표시되며, 초안 끝에 "추가하면 더 좋은 항목(관련 근거·첨부·참조처 등)"을 별도로 안내해 드립니다.
출력은 어떤 형태로 나오나요?
작성일자·수신·경유·참조·제목과 번호로 구분된 본문(인사말·배경·요청+회신기한), 첨부, 서명 순서의 텍스트 초안으로 나옵니다. 복사해서 기존 공문 양식(한글·워드 등)에 그대로 붙여넣어 사용하면 됩니다.
수신처에 따라 문체가 달라지나요?
네. 수신처 유형에 따라 호칭이 자동으로 전환됩니다. 감리단은 "귀 단", 조합은 "귀 조합", 그 외(발주처·고객·협력사)는 "귀 사"로 본문 전체에서 일관되게 사용하며, 종결어미는 ~니다/~드립니다/~바랍니다로 통일됩니다.
없는 사실이나 수치를 임의로 만들어내지는 않나요?
아니요. 입력되지 않은 사실·수치·인명·금액·날짜는 추측해 작성하지 않고 [OOO]로 비워 둡니다. 단, 작성일자가 없을 때 오늘 날짜를 자동 기입하는 것은 예외입니다.
어떤 자료를 기준으로 작성되나요?
사내 표준인 "현대건설 대외 공문 작성 규칙"(문체·호칭·구조·용어)과 "공문양식"(문서번호·수신·경유·첨부·서명부 서식)을 참고자료로 두고, 이를 기준으로 일관된 초안을 생성합니다.
