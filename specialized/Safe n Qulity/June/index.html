TRY 01 · 생성

본사 요청 HTML파일 만들기

아래 프롬프트를 그대로 붙여넣어 현장점검 개선조치 요청서.html 파일 생성을 요청합니다.

프롬프트 보기
너는 엔터프라이즈급 사내 웹 양식을 개발하는 시니어 프론트엔드 개발자야. 외부 라이브러리 없이 오직 순수 HTML, CSS, Vanilla JavaScript만을 사용하여 단일 파일(.html)로 된 「본사 현장점검 개선조치 요청서」를 작성해 줘. [🔥 가장 중요한 지시사항: 파일로 제공할 것] 결과물을 절대 채팅창에 마크다운 텍스트 코드 블록으로만 길게 늘어놓지 마. 반드시 네가 지원하는 'Artifact(아티팩트)', '파일 생성(File Creation)', 또는 '코드 내보내기' 기능을 사용하여, 내가 즉시 현장점검 개선조치 요청서.html 이라는 실제 파일로 다운로드하거나 독립된 화면에서 열어볼 수 있도록 결과물을 제공해. 코드를 중간에 생략하는 것은 절대 금지야. ### 1. 디자인 및 UI/UX (CSS 최적화) * **브랜드 컬러**: 현대건설 스타일 반영 (Primary Green: #00A652, Primary Blue: #0C4CA3, Accent Yellow: #FDB813). * **타이포그래피**: 폰트는 Pretendard, Malgun Gothic, sans-serif 사용. * **스타일**: 불필요한 장식은 배제하고, 입력 폼과 표(Table) 중심의 깔끔하고 전문적인 공문서 레이아웃 구현. 부드러운 그림자와 라운드 처리(border-radius)로 모던함 강조. ### 2. 레이아웃 구조 (HTML) * **상단 고정 툴바**: 화면 상단에 고정. '현장 PDF 저장/인쇄', '본사용 HTML 저장', '입력 초기화' 버튼 배치. (자동 저장이 지원되므로 수동 임시저장 버튼은 제외하거나 보조용으로만 둠). * **메인 문서 영역 (최대 너비 1200px)**: 1. **헤더**: 문서 제목 (본사 현장점검 개선조치 요청서) 및 기본 정보 테이블 (발신, 수신, 점검일, 작성일 등). 2. **안내 박스**: 본사 작성용, 현장 조치용 가이드를 간결하게 2단 배치. 3. **섹션 1 (본사 점검사항)**: 사진번호, 점검사진(미리보기), 구분, 점검의견, 조치 요청사항, 중요도(상/중/하 색상 구분), 삭제 버튼이 있는 테이블. 4. **섹션 2 (현장 조치결과)**: 사진번호, 완료일, 조치완료 사진(미리보기), 조치내용, 삭제 버튼이 있는 테이블. * 각 섹션 하단에 '행 추가' 버튼 배치. ### 3. 핵심 기능 (JavaScript 최적화) 복잡한 로직을 피하고 가볍게 구현해. * **이미지 미리보기**: input type="file"로 이미지 업로드 시, FileReader를 통해 표 내부 미리보기 영역에 Base64로 즉시 표시 (클릭 시 확대되는 간단한 모달창 포함). * **동적 행 관리**: 행 추가/삭제 기능 및 사진번호(사진 1, 사진 2...) 자동 재정렬. * **상태 동기화 및 다운로드**: * 현재 입력된 input, textarea, select의 값(value)을 DOM 속성(attribute)으로 동기화. * **본사용 HTML 저장**: 위 동기화 후 현재 document.documentElement.outerHTML을 .html 파일로 다운로드. ### 4. 🚀 실시간 자동 저장 기능 (LocalStorage) * 사용자의 데이터 유실을 막기 위해 **자동 저장(Auto-save)** 로직을 완벽하게 구현해. * 사용자가 텍스트를 입력(input, keyup, change 이벤트), 옵션을 선택, 이미지를 첨부, 행을 추가하거나 **삭제(deleteRow)** 할 때마다 즉시 문서 영역의 HTML 상태를 localStorage에 자동 저장해야 해. * 페이지가 로드될 때(DOMContentLoaded), localStorage에 저장된 데이터가 있다면 자동으로 불러와서 화면에 복원되도록 구현해. (이미지 미리보기 클릭 이벤트 등도 함께 복원할 것). ### 5. 인쇄 모드 (@media print) * 완벽한 A4 가로(Landscape) 포맷 적용 (@page { size: A4 landscape; margin: 10mm; }). * 버튼, 툴바, 파일 첨부 인풋, 가이드 박스 등 UI 요소 숨김 처리. * 입력 폼의 테두리를 투명하게 만들어 일반 문서처럼 출력되도록 최적화. ### 6. 초기 샘플 데이터 * 빈 껍데기가 아니라, 실제 건설현장 데이터(예: 비산먼지 살수차 운행 미흡, 세륜기 슬러지 지연, 법면 덮개 불량 등)가 사진 1~3까지 미리 입력된 상태로 초기 HTML을 구성해. 조치결과 테이블도 3행을 미리 만들어 둬. 다시 한번 강조하지만, 코드를 생략 없이 모두 작성한 뒤 반드시 내가 다운로드할 수 있는 하나의 .html 파일 형태로 출력해 줘

4FAQ
Copilot이 갑자기 엉뚱한 말로 시작하면 어떻게 하나요?
모델이나 대화 상태가 초기화된 경우일 수 있습니다. 상단의 모델 선택 상태를 먼저 확인하고, "자동"으로 초기화 되어 있을 시에, 최신 모델로 재설정 해주어야 합니다.
왜 꼭 파일로 달라고 해야 하나요?
HTML 파일은 코드가 길어서 채팅창에 그대로 나오면 복사 중에 빠지거나 깨질 수 있습니다. 파일로 받아야 바로 열어보고, 저장과 인쇄 기능까지 제대로 확인할 수 있습니다.
HTML 파일을 열면 무엇부터 확인하면 되나요?
먼저 파일이 정상적으로 열리는지 보고, 그다음 표 구조와 이미지 미리보기, 행 추가/삭제, 자동 저장, HTML 저장, 인쇄/PDF 기능을 차례로 확인하면 됩니다.
